改波形：拖动高低电平之间的竖边；“画高 / 画低”可拖出区间。同电平相遇时会合并。双击区间翻转电平，双击信号名可重命名。

改时间：选择边沿后点“精确修改”，输入 1n、200p 等时间。吸附仅作用于鼠标操作；按住 Alt 临时关闭吸附。

看更多：调低行高，使用信号名右侧的上下箭头排序；Ctrl＋滚轮缩放，Shift＋滚轮横向移动。“适合”显示一个完整大周期。显示排序不会改变 VA 端口顺序。

继续协作：每次松开鼠标后自动保存。看到“已保存”后，在聊天里告诉我“改好了”及下一步要求；窗口会接收后续工程修改。导出 VA 会同时保存一份工程快照。
