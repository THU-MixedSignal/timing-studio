# 验证范围

公开 skill 发行版 0.1.0 基于已经维护的窗口与 VA 导出器。本次整理只改变安装、路径定位、环境准备和启动；整数 fs 模型、编辑语义与 VA 编译核心保持相同。package-manifest.json 保存每个文件的字节哈希及来源快照。

## 已有核心验证

2026-10-20 的同一模型版本完成 60/60 组“生成 → 真实窗口微调 → VA 导出 → Spectre 对照”，包括 1～50 路各一组和 10 组专项，共 1371 路，周期 20 ps～1 ms。54 组首次生成使用约定中文模板解析，6 组独立解释指令；这不等于任意自然语言都已正确解析。

实际对照检查了 110,777,913 个电压值、229,044 个门限时刻和 76,390 段斜坡。最密集的 50 路示例单线程仿真约 39.24 分钟，峰值约 3098 MiB；另有一个示例因 split 将来可能成为保留字而有 5 条警告。测试通过的精度受仿真设置与对照容差限制。

这些是已有核心测试，不是本次打包重新运行的仿真。原始仿真数据含开发环境现场，未放入公共包。公共包里的测试可自行重跑，不能代替仿真器检查。

## 本地回归

`python -B run-tests.py` 执行包内标准库测试：时间解析、有限/无限重复与 VA 事件、拖动合并、保存/恢复、revision 冲突保护、HTTP 访问边界、工程与 VA 一致性，以及公共入口的包内定位。不要将这些测试称为 Spectre 仿真。

移位安装、私有 Python 引导及真实浏览器试用的最终结果记录在 release-checks.json。发布前应从新解压目录重做：doctor → 独立会话 → 编辑 → 读回 → 导出 → 恢复 → 停止。Windows 以外的图形窗口和独立干净电脑尚未验收。
